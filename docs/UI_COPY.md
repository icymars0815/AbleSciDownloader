# 界面文案规范与对照表

本文档记录界面文案的统一术语、写作规则，以及主要的新旧文案对照。适用范围：`index.html`、`app.js`，以及 Python 端生成的用户可见消息（事件、备注、错误提示）。

产品名称：界面统一称“科研通下载器”（ASCII：AbleSciDownloader；内部代号 KYTDL 仅用于文件名、MCP 键名等标识）。不得暗示本软件是科研通的产品或官方程序。

## 1. 写作规则

- 使用中性的产品口吻，不使用第一人称（“我/我们”），不出现对开发者的指令或设计文档引用。
- 不暴露内部术语：stage、gate、pipeline、OA、ETA、rules_version、批次 ID 等。
- 标签尽量不超过 8–10 个字；设置项下方用一行平实的说明。
- 警告以明确的主语开头：“费用提示：”“注意：”“隐私提示：”“说明：”。
- 事件日志使用过去式的客观陈述，不使用感叹号，不使用道歉语。示例：“已发布求助《…》，悬赏 10 积分。”
- 所有安全相关的提示（费用、驳回处罚、AI 数据发送、隐私）保留原有含义。

## 3. 控件规范

界面基于本地打包的 Bootstrap 5.3.3（`static/vendor/bootstrap-5.3.3/`，MIT，无 CDN、无构建步骤）：开关为 `.form-switch`，多选一为 `.btn-group` + `.btn-check`，确认对话框为 Bootstrap Modal，消息面板为 Offcanvas，提示为 Toast，深浅色由 `data-bs-theme` 跟随系统。

- 开关类设置（开启 / 关闭）统一使用开关控件（`role="switch"`，`aria-checked`），键盘 Space / Enter 可切换。
- 需要二次确认的开关（高速通道、自动驳回、自动求助、自动采纳、AI 辅助、MCP 权限、最低悬赏自动接受）在确认前不改变显示状态，确认后才切换。
- 多选一设置（高速通道的关闭 / 智能 / 强制、人机验证处理方式、最低悬赏上调的询问 / 自动接受、密钥保存方式）统一使用分段控件（`role="radiogroup"`）。
- 悬赏积分只能选择科研通官方档位：10、20、30、50、80、100、150、200。超过当前积分的档位不可选。服务端同样只接受这些档位。
- 数值类设置在输入框右侧显示单位（分钟、秒、次、%、KB/s）。
